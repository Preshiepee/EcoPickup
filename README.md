# ♻ EcoPickup – Waste Pickup Scheduler

EcoPickup is a simple web application that helps users schedule waste pickups, manage their profiles, and view their pickup history. It aims to promote cleaner communities through an easy-to-use digital waste management system.

## Features
- User Registration & Login
- Dashboard
- Schedule Waste Pickup
- View Pickup History
- Update User Profile
- Responsive User Interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Local Storage

## How to Run
1. Download or clone the project.
2. Open the project folder.
3. Launch `index.html` in your browser or use Live Server in VS Code.
